# 2026-07-08 开发记录：门派系统与贡献兑换

## 目标

继续开发下一部分，补上门派玩法雏形：

```text
加入宗门 -> 宗门任务 -> 贡献点 -> 宗门兑换
```

## 完成内容

### 门派数据

- 新增 `src/data/sects.ts`。
- 当前门派：
  - 青云门
  - 丹霞谷
  - 散修盟
- 门派配置包含：
  - 门派名称
  - 阵营倾向
  - 描述
  - 加入境界要求
  - 宗门任务
  - 贡献兑换

### 宗门任务

- 新增 `src/systems/sectSystem.ts`。
- 支持随机完成当前宗门任务。
- 任务消耗：
  - 气血
  - 灵力
- 任务奖励：
  - 贡献点
  - 灵石
  - 修为
  - 材料或丹药

### 宗门兑换

- 使用贡献点兑换宗门资源。
- 当前可兑换：
  - 灵息草
  - 低阶妖核
  - 聚气丹
  - 筑基丹
- 兑换会检查：
  - 贡献是否足够
  - 当前境界是否满足兑换要求

### 存档更新

- 玩家数据新增 `sectContribution`。
- 旧存档读取时会自动补齐贡献字段。

### 界面接入

- 新增 `宗门` 面板。
- 未加入宗门时显示可拜入宗门。
- 加入后显示：
  - 当前宗门
  - 当前贡献
  - 宗门任务按钮
  - 宗门兑换列表
  - 宗门日志
