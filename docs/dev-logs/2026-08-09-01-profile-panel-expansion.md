# 2026-08-09：首页个人信息面板扩展

## 目标

扩大世界地图首页左侧角色信息抽屉的展示面积，提高境界、修为、气血、灵力和基础属性的可读性。

## 实现

- 桌面端抽屉最大宽度从 `560px` 扩展至 `680px`，并增加内边距与可用高度。
- 角色身份信息独占首行；修为、气血、灵力状态条与灵石、寿元、灵根、宗门、洞府、心境数据在下方双栏并列展示。
- 调整状态条、数值和字段标签字号，使扩展后的面板层级更清晰。
- 手机端将抽屉宽度扩展为接近屏幕全宽，同时仍使用游戏壳高度限制，超出时仅在面板内容区滚动，不产生页面纵向滚动。

## 验证

- 执行 `npm.cmd run build`，TypeScript 检查与 Vite 生产构建均通过。

## 后续排布优化

- 将面板调整为三段式：身份信息、三项状态条、六项基础属性卡。
- 桌面端使用“状态条 + 两列属性卡”的并列布局，避免寿元等长数值挤压换行。
- 增加窄屏 CSS 兜底；即使嵌入式浏览器未及时添加移动端类名，也会自动切换为纵向分段布局，消除横向滚动。
- 在 `390 × 844` 窄屏与默认桌面尺寸下完成界面复查。

## 手机端状态区优化

- 修为改为独占首行，完整展示当前修为与进度条。
- 气血、灵力在第二行并列显示，提升数值与颜色进度条的对照效率。
- 伤势出现时独占整行，使用独立色调；惩罚说明过长时自动省略，但保留完整文本提示。
- 已在 `390 × 844` 手机视口中复查，状态区无横向溢出。

## 数值边界修复

- 为状态条数值与属性卡数值统一增加可收缩、框内省略和等宽数字规则。
- 属性卡与状态卡启用内容裁剪，后期较长的修为、寿元或资源数值不会突破卡片边界。
- 在 `390 × 844` 手机视口复查，当前所有数值均保留在所属状态框内。

## 展示框重构

- 个人信息框调整为“身份头部 → 核心状态卡 → 基础属性卡”的三段信息架构。
- 桌面端三项核心状态与六项基础属性均采用三列等宽卡片，属性对齐更稳定。
- 手机端保持修为首行、气血与灵力并列、基础属性两列的紧凑层级。
- 为修为、气血、灵力与伤势分别赋予对应色调，便于快速识别状态类型。
- 已在默认桌面尺寸和 `390 × 844` 手机视口完成视觉复查。

## 可读性优先调整

- 身份区统一左对齐，角色名、境界与当前位置按阅读顺序排列，去除分散的左右对置关系。
- 手机端将修为、气血、灵力调整为纵向大状态条，提高文字、数值与进度条的辨识度。
- 手机端属性卡保留两列，并提高字号、留白和卡片间距；面板空间不足时仅在抽屉内部滚动。
- 已在桌面与 `390 × 844` 手机视口复查，无横向溢出。

## 横屏手机适配

- 针对 `844 × 390` 横屏手机视口，个人信息框切换为“身份头部 + 状态/属性双栏”的一屏布局。
- 左栏展示修为、气血、灵力；右栏以两列六格展示灵石、寿元、灵根、宗门、洞府、心境。
- 收紧横屏字号、卡片内边距和进度条高度，移除抽屉内部滚动条。
- 增加媒体查询兜底，避免部分嵌入式浏览器未挂载 `game-mobile` 类时失去横屏布局。
