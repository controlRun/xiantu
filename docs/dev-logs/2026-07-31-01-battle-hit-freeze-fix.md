# 2026-07-31：对战命中卡死修复

## 背景
玩家反馈对战中箭矢射出并命中对手后，偶发停留在命中画面，后续伤害数字、敌方回合或结算界面不继续推进。

## 问题定位
- 箭矢动画在碰撞命中后会停止自身飞行动画，随后依赖上层 `onHit` 回调继续推进战斗状态。
- 若命中结算回调发生异常，或 React 尚未完成 `shootArrow` 之后的状态刷新，后续 `applyPlayerShot` / `skipPlayerShot` 可能拿到旧的玩家与战斗状态。
- 旧状态回写会覆盖本次射击产生的扣箭、扣灵力、待结算伤害等变化，表现为战斗状态机推进异常。

## 本次修复
- 命中结算和落空结算改为使用本次 `shootArrow` 返回的 `player` / `duel` 快照。
- `BattleScreen` 将本次射击快照传回 `App`，由 `App` 基于快照调用 `applyPlayerShot` 或 `skipPlayerShot`。
- 保留动画层命中兜底和阶段看门狗，避免异常时永久停留在飞行阶段。

## 验证
- 已执行 `npm.cmd run build`，TypeScript 与 Vite 生产构建通过。
