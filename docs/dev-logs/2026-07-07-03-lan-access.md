# 2026-07-07 开发记录：局域网访问优化

## 目标

让同一 WiFi 下的手机或其他设备可以访问本机 Vite 开发服务器。

## 问题

原开发服务器脚本为：

```json
"dev": "vite --host 127.0.0.1"
```

该配置只监听本机回环地址，其他设备无法访问。

## 完成内容

- 将默认开发脚本改为监听所有网卡：

```json
"dev": "vite --host 0.0.0.0"
```

- 保留本机访问脚本：

```json
"dev:local": "vite --host 127.0.0.1"
```

- 将预览脚本也改为局域网可访问：

```json
"preview": "vite preview --host 0.0.0.0"
```

## 局域网访问地址

当前 WiFi 局域网 IP：

```text
192.168.31.98
```

手机浏览器访问：

```text
http://192.168.31.98:5173/
```

本机仍可访问：

```text
http://127.0.0.1:5173/
```

## 验证

- Vite 监听地址从 `127.0.0.1:5173` 变为 `0.0.0.0:5173`。
- 本机访问 `http://192.168.31.98:5173/`：返回 200 OK。
- 手机端已确认可以访问。

## 后续

继续保持默认 `npm.cmd run dev` 支持局域网访问，方便手机端预览和调试。
