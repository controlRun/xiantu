# 2026-07-08 开发记录：炼丹系统与丹药产出

## 目标

继续开发下一部分，将战斗掉落的材料接入炼丹系统：

```text
材料 -> 丹方 -> 炼制判定 -> 丹药产出 -> 修炼/突破
```

## 完成内容

### 丹方数据

- 新增 `src/data/recipes.ts`。
- 当前丹方：
  - 聚气丹
  - 筑基丹
- 丹方配置包含：
  - 产出物品
  - 所需材料
  - 灵石消耗
  - 基础成功率
  - 神识门槛
  - 丹方说明

### 炼丹系统

- 新增 `src/systems/alchemySystem.ts`。
- 支持炼丹条件检查：
  - 神识是否足够
  - 灵石是否足够
  - 材料是否足够
- 支持成功率计算：
  - 基础成功率
  - 神识加成
  - 悟性加成
  - 气运加成
- 支持炼制结算：
  - 成功时消耗材料并获得丹药
  - 失败时消耗材料
  - 筑基丹失败时可回收少量灵息草

### 界面接入

- 新增 `炼丹` 面板。
- 显示每个丹方的：
  - 产出
  - 材料
  - 灵石消耗
  - 成功率
  - 缺失条件
- 支持点击 `炼制`。
- 最近炼丹结果会显示炼丹日志。
