# 《仙途》开发方案

## 一、项目定位

游戏名：仙途

主题：凡人修仙，逆天改命，求道长生。

推荐类型：

- 单机修仙 RPG
- 半放置养成
- 回合制战斗
- 事件探索
- 资源经营

核心体验：

玩家从一介凡人开始，通过修炼、拜入门派、历练战斗、探索秘境、炼丹炼器、突破境界，逐步走向长生大道。

核心循环：

```text
修炼积累修为
-> 接任务 / 探索秘境 / 外出打怪
-> 获得资源、功法、丹药、装备
-> 炼丹、强化、学习技能
-> 突破境界
-> 解锁新地图、新门派地位、新玩法
-> 继续更高层次修仙
```

## 二、世界观框架

### 世界层级

1. 凡俗界
   - 新手区域。
   - 包含村镇、山林、低阶妖兽、散修、凡人任务。

2. 修真界
   - 中期主要舞台。
   - 包含门派、坊市、洞府、灵脉、秘境、宗门纷争。

3. 上古遗迹
   - 高风险高收益区域。
   - 包含禁制、残魂、古修传承、稀有材料。

4. 灵界 / 仙界
   - 后期扩展内容。
   - 可作为长线目标和版本扩展方向。

### 主要势力

- 正道宗门：重视声望、门规、任务体系。
- 魔道宗门：资源获取快，但有因果、心魔、仇杀风险。
- 散修联盟：自由度高，但缺少稳定资源。
- 妖族势力：可做特殊剧情或后期阵营。
- 商会 / 炼丹阁 / 炼器坊：经济和材料系统核心。

## 三、角色成长系统

### 基础属性

- 寿元：到期未突破则死亡，后续可扩展轮回机制。
- 修为：突破境界的核心经验。
- 气血：生命值。
- 灵力：释放法术资源。
- 攻击：物理或法术伤害。
- 防御：减伤。
- 神识：影响命中、探索、炼丹成功率。
- 根骨：影响修炼速度。
- 悟性：影响功法领悟、技能升级效率。
- 气运：影响奇遇、掉落、突破偏向。
- 心境：影响突破、心魔、走火入魔概率。
- 丹毒：服用丹药过多产生的负面累积。

### 境界设计

```text
凡人
炼气 一至九层
筑基 初期 / 中期 / 后期 / 圆满
金丹 初期 / 中期 / 后期 / 圆满
元婴
化神
炼虚
合体
大乘
渡劫
真仙
```

### 突破机制

- 需要修为达到当前境界上限。
- 需要突破材料，例如筑基丹、凝金丹、破婴丹。
- 有成功率。
- 受根骨、心境、功法、丹药、气运影响。
- 失败可能损失修为、受伤、减少寿元、增加心魔。
- 大境界突破可加入雷劫玩法。

## 四、主要玩法系统

### 修炼系统

修炼方式：

- 闭关修炼：稳定获得修为，消耗时间。
- 灵石修炼：消耗灵石，提高效率。
- 丹药辅助：快速提升，但增加丹毒。
- 洞府加成：洞府灵气越高，修炼越快。
- 功法加成：不同功法决定成长方向。

功法类型：

- 主修功法：决定修炼速度、突破难度、属性倾向。
- 攻击法术：战斗技能。
- 身法遁术：闪避、先手、探索逃脱。
- 神识秘术：侦查、控场、炼丹辅助。
- 炼体法门：提高气血、防御、抗雷劫能力。

### 门派系统

加入门派后解锁：

- 宗门任务
- 贡献点
- 藏经阁
- 丹房
- 炼器堂
- 师徒系统
- 宗门大比
- 职位晋升
- 门派剧情

职位等级：

```text
杂役弟子
外门弟子
内门弟子
核心弟子
亲传弟子
长老
太上长老
```

门派贡献用途：

- 兑换功法。
- 兑换丹药。
- 申请洞府。
- 进入秘境。
- 购买材料。
- 请教长老。

### 战斗系统

推荐前期做成回合制自动或半自动战斗。

战斗流程：

```text
进入战斗
-> 判断先手
-> 玩家选择技能 / 自动释放
-> 怪物行动
-> 状态结算
-> 胜利掉落 / 失败惩罚
```

技能设计：

- 普攻：不消耗灵力。
- 法术：消耗灵力，造成高伤害。
- 防御：降低本回合伤害。
- 遁术：提高闪避或逃跑概率。
- 控制：眩晕、缠绕、封灵。
- 持续状态：中毒、灼烧、流血、护盾。

怪物分类：

- 野兽：产出低阶材料。
- 妖兽：产出妖丹、兽骨、皮毛。
- 邪修：产出功法残页、法器。
- 秘境守卫：产出稀有材料。
- 上古残魂：产出传承、神识类资源。

### 探索秘境系统

秘境是游戏的主要冒险内容。

秘境由多个节点组成：

```text
入口
-> 随机事件
-> 战斗
-> 采集
-> 禁制
-> 宝箱
-> 小 Boss
-> 传承 / 最终 Boss
```

事件类型：

- 灵草采集
- 妖兽袭击
- 古修洞府
- 禁制破解
- 迷雾岔路
- 受伤修士求助
- 魔修埋伏
- 机缘传承
- 空间裂缝

探索资源：

- 体力
- 神识
- 时间
- 秘境令牌

风险机制：

- 死亡或重伤。
- 损失物品。
- 增加心魔。
- 被其他修士追杀。
- 获得因果标记。

### 炼丹系统

炼丹流程：

```text
收集丹方
-> 收集药材
-> 选择丹炉
-> 开始炼制
-> 判定品质
-> 获得丹药 / 炸炉 / 废丹
```

影响因素：

- 丹方等级
- 药材品质
- 丹炉品质
- 神识
- 炼丹熟练度
- 火候控制

丹药类型：

- 聚气丹：增加修为。
- 筑基丹：辅助突破筑基。
- 疗伤丹：恢复气血。
- 回灵丹：恢复灵力。
- 清心丹：降低心魔。
- 洗髓丹：提升根骨。
- 解毒丹：清除负面状态。

丹药品质：

```text
废丹
下品
中品
上品
极品
丹纹
丹云
```

## 五、MVP 最小可玩版本

第一版只做核心闭环：

1. 创建角色
   - 随机灵根、根骨、悟性、气运。

2. 修炼
   - 点击或等待获得修为。

3. 境界突破
   - 凡人 -> 炼气一层 -> 炼气九层 -> 筑基。

4. 简单战斗
   - 回合制打妖兽，获得灵石、材料、丹药。

5. 门派
   - 加入一个宗门，做任务得贡献，兑换功法。

6. 秘境
   - 随机 5 到 8 个事件节点。

7. 炼丹
   - 实现 3 到 5 种丹药。

8. 存档
   - 本地保存角色数据。

MVP 目标链路：

```text
创建角色 -> 修炼 -> 打怪 -> 获得材料 -> 炼丹 -> 突破 -> 加入门派 -> 探索秘境
```

## 六、技术框架

第一版使用：

```text
React + TypeScript + Vite
```

原因：

- 修仙游戏大量内容是数据驱动 UI。
- React 适合属性面板、背包、门派、战斗日志、事件选择。
- TypeScript 适合管理角色、物品、技能、怪物等数据结构。
- Vite 启动快，适合快速迭代原型。

## 七、开发步骤

1. 搭建项目
   - 建立前端工程、基础页面、存档结构。

2. 做玩家数据模型
   - 角色属性、境界、背包、灵石、寿元。

3. 做修炼与突破
   - 打通游戏主轴。

4. 做物品系统
   - 丹药、材料、功法、装备先统一成 Item。

5. 做战斗系统
   - 先做简单回合制，再扩展技能和状态。

6. 做探索系统
   - 用随机事件驱动秘境玩法。

7. 做炼丹系统
   - 让探索材料能转化为成长资源。

8. 做门派系统
   - 加入任务、贡献、藏经阁、职位晋升。

9. 做 UI 打磨
   - 境界面板、日志、背包、战斗反馈、事件选择。

10. 做平衡和数值表
    - 修为需求、掉落概率、突破概率、怪物强度。

## 2026-07-24 补充：对战稳定性

- 修复秘境伏击等自动战斗路径，确保发射后会按命中率结算命中或落空。
- 交互对战中，箭矢命中视觉目标后仍会受到命中率判定影响。
- 当前箭矢耗尽时，战斗界面自动切换到下一种可用箭矢或灵力箭。
- 敌方射击动画读取结构化战斗状态，不再依赖解析日志文案。
- 实战撤退会生成失败结算并消耗时间，演武退出仅清理对战状态。

## 2026-07-31 补充：对战命中卡死修复

- 修复玩家箭矢视觉命中目标后，若命中结算未能及时推进状态机，界面停留在飞行阶段的问题。
- 命中、闪避、落空结算统一基于本次发射返回的玩家与对战快照，避免 React 状态异步刷新导致旧战局覆盖新战局。
- 保留对战阶段看门狗与箭矢动画兜底，让异常情况下仍能回到瞄准、敌方回合或结算界面。
- 后续对战优化可继续补充回放日志、受击部位倍率显示、箭矢轨迹调参和移动端瞄准手感。
